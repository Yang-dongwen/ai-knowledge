# 知识库 · 移动端 H5（Phase M2 对齐）

浏览器本地预览 / 手机局域网访问，**无需**微信开发者工具。

与 PC、微信小程序共用同一后端：`okx-bot` 的 JWT + `/api/v1/kb/*`。

> **不是一套前端代码**：`kb-mobile`（H5）与 `kb-miniprogram`（微信）是两套 UI，只共享 API 与账号数据。

版本 **0.6.0 H5**。

## 启动

```bash
# 1. 后端 okx-bot :8080
# 2. 本目录
cd kb-mobile
npm install
npm run dev
```

浏览器打开 **http://127.0.0.1:5174**。开发服务器已将 `/api` 代理到 `http://127.0.0.1:8080`。
