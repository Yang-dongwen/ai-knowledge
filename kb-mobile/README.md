# 知识库 · 移动端 H5

浏览器本地预览 / 手机局域网访问，**无需**微信开发者工具。

与 PC 端、微信小程序共用同一后端：`okx-bot` 的 JWT + `/api/v1/kb/*`。

> **不是一套前端代码**：`kb-mobile`（H5）与 `kb-miniprogram`（微信）是两套 UI，只共享 API 与账号数据。

## 启动

```bash
# 1. 后端 okx-bot 先跑起来（:8080），并已建 kb 表（含分享字段）
# 2. 本目录
cd kb-mobile
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 **http://127.0.0.1:5174**）。

开发服务器已把 `/api` **代理**到 `http://127.0.0.1:8080`。

## 公开分享

详情 → **分享** → 开启后复制 `当前站点/s/{token}`。  
无需登录即可打开；正文内媒体已由后端改写为公开路径。
