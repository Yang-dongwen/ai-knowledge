# AI 视频生成 — 极简说明

**给谁看**：只想快速搞懂「干什么、谁做、别踩坑」  
**详细设计**：见同目录 [`AI视频生成_架构设计方案.md`](./AI视频生成_架构设计方案.md)（长文，实现时再翻）  
**日期**：2026-07-13  

---

## 一句话

用户在网页里输入**提示词** → 后端用 AI 写分镜、生成配音 → **Remotion** 渲成 MP4 → 网页播放/下载。

---

## 三步主链路

```
① 网页（Vue）          ② 后端（Java）              ③ 渲染（Remotion）
   填提示词、看进度   →    AI 分镜 + TTS + 存任务  →    按脚本画出 MP4
   播放 / 下载        ←    返回 taskId / 状态      ←    把文件写回磁盘
```

不用一次记住表结构、队列、降级策略——**先把这三步记住**。

---

## 三个工程各自干什么

| 工程 | 技术 | 干什么 | 不干什么 |
|------|------|--------|----------|
| **okx-trading-web** | Vue 3 | 生成页、表单、任务列表、进度、播放器 | **不**做视频帧渲染、**不**装 Remotion |
| **okx-bot** | Spring Boot | 接任务、调 LLM（建议 LangChain4j）、调 TTS、调渲染服务、存库落盘 | **不**在 Java 里画动画 |
| **aigen-remotion**（以后新建） | React + Node + Remotion | 视频模板 + 导出 MP4 | **不**做登录、列表、业务 API |

> 和现有「视频提取」一样：网页提交 → 后端干重活 → 网页看结果。  
> 提取是「链接触发」；生成是「提示词触发出新片」。

---

## 为什么不能全塞进前端？

1. **okx-trading-web 是 Vue**，Remotion 模板必须是 **React**，两套框架硬塞会乱。  
2. 导出 MP4 很吃 CPU，适合**服务器/本机 Node**，不适合让用户浏览器渲几分钟。  
3. 前端只适合：**提交 → 等 → 播已经生成好的文件**。

所以：

- ✅ 生成功能的**页面**在 `okx-trading-web`
- ✅ 出片引擎是**独立小项目**（实现时再建）
- ❌ 不是「Vue 里写动画就当成品视频」

## 后端最简心智模型

```
用户点「生成」
    → 插入一条任务（排队中）
    → 后台慢慢跑：
         1. 让 AI 写出「分镜脚本」（结构化 JSON，不是随便一段话）
         2. 按文案生成语音（TTS）
         3. 把脚本交给 Remotion 渲染 MP4
    → 成功：网页能播；失败：显示错误，可重试
```

- **AI（LangChain4j）**：主要负责「提示词 → 分镜 JSON」  
- **Remotion**：负责「分镜 JSON → 画面」  
- **Java**：当项目经理，串步骤、记状态、存文件  

不要让 AI 框架去管下载、渲染、排队——那些仍是 Java 流水线的事。

---

## 前端最简心智模型

一个新页面（例如 `/video-generate`）即可：

1. 输入框：提示词  
2. 选项：模板 / 时长 / 竖屏或横屏（能少则少）  
3. 按钮：生成  
4. 列表：任务状态（排队 / 生成中 / 成功 / 失败）  
5. 成功后：播放 + 下载  

细节交互、分镜编辑器都可以以后再加。

---

## 和「视频提取」别搞混

| | 视频提取（已有） | AI 视频生成（新建） |
|--|------------------|---------------------|
| 入口 | `/video-extract` | `/video-generate`（拟） |
| 输入 | 视频链接 | 提示词 |
| 输出 | 摘要 / 原文案等 | **新的 MP4** |
| 重活 | 下载、语音识别、总结 | AI 分镜、配音、Remotion 渲染 |

两套功能并列，**不要塞进同一张任务表**。

---

## 建议落地顺序（极简）

| 顺序 | 做什么 | 目标 |
|------|--------|------|
| 1 | Java：任务表 + 接口 + 假进度 | 前端能跑通提交/列表 |
| 2 | Vue：生成页壳子 | 能点、能看状态 |
| 3 | LangChain4j：提示词 → 分镜 JSON | 规划步骤真实可用 |
| 4 | 新建 `aigen-remotion`：1 个竖屏模板 + 能出片 | 真有 MP4 |
| 5 | TTS 接上 | 有声音 |
| 6 | 再谈多模板、分镜编辑、配图… | 体验增强 |

**第一版成功标准**：输入一句话 → 几分钟内网页里能播一条竖屏短视频。
