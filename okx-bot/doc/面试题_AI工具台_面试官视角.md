**适用：** 个人项目「AI 智能内容工具台 + 个人知识库」（简历同名条目）  
**对照代码：** `okx-bot` 当前实现，不是规划文档里的「拟」  
**配合：** [面试准备_问题与项目讲解.md](./面试准备_问题与项目讲解.md) 讲叙事；本文练被追问。

## 题库（开场题 + 追问）

### 0. 开场

**Q：用 2 分钟讲这个项目。你解决什么问题？为什么不直接调 ChatGPT / 扣子？**

追问：

- 用户是谁？现在有没有真实用户？为什么暂不开放注册？
- 「独立全栈偏后端」——前端、部署、产品决策各占多少？哪一块你最虚？
- 如果只能留一个技术亮点给下一轮，你留哪条？为什么？

面试官在听：有没有产品约束，还是在堆功能清单。诚实说「自用 + 练工程化、未开放注册」比编 DAU 强。

### 1. 任务系统（必问）

**Q：四个工具为什么各一张任务表、各一套状态机，而不是一张 `ai_task` 加 `type`？**

追问：

- 状态枚举分别长什么样？视频提取和成片的中间态差在哪？
- HTTP 请求线程里做什么、异步线程里做什么？卡住下载/Whisper 会怎样？
- 进程重启时，库里还是 `DOWNLOADING` 的任务怎么办？槽位会不会被占死？
- 「每类工具自己的并发槽」——槽存在哪？内存还是 DB？多实例还能用吗？
- 为什么不用 Kafka / Redis 队列？单机小机器这个选择现在还成立吗？
- 暂停和取消怎么实现的？协作式是什么意思？正在跑 FFmpeg 的进程杀不掉怎么办？
- 同一用户连提 10 个任务，系统怎么挡？会员校验在哪一层？

代码锚点：`VideoTaskScheduler`（`MAX_CONCURRENT = 2` + `TaskSlotKernel("video")`）；启动 `recoverOrphanRunningTasks` 把进行中标 FAILED。成片/文章/文生图各有自己的 Scheduler，**不是全局一把槽**。

### 6. 认证、会员、多端

**Q：JWT 无状态，改密码或登出之后旧 token 为什么会失效？**

追问：

- claims 里有没有 `role`？没有的话权限每次请求怎么取？有的话改角色何时生效？
- `token_version` 什么时候加一？只改密，还是登出也加？
- 注册验证码和找回密码验证码能否混用？未注册邮箱点找回，接口返回什么（防枚举）？
- 微信小程序登录：未绑定邮箱怎么走？openid 存在哪？
- 会员过期是定时任务扫，还是 `me()` 时惰性降级？超管会不会被降成 USER？
- 支付简历写了 Mock——订单成功后会员字段怎么改？支付宝回调验签你写了但没上线，缺什么？
- 为什么超管不能给自己买会员？

事实（不要说错）：

- JWT claims：`sub`=userId、`email`、`tv`（token_version），**不含 role**；每次 `loadById` 读库。
- **改密**会 `tokenVersion + 1`，过滤器比对失败则拒绝；**登出只是前端删 token**，服务端不吊销。
- 找回密码：未注册也返回成功，不发信。
- 会员：`MemberStatusService.isActive`；`me()` 里对过期 MEMBER 惰性降 USER；SUPER_ADMIN 不过期、也不走自助买会员。
- 支付：Mock 闭环可用；支付宝 Adapter 已写、默认关闭；微信 notify 明确未实现。

**Q：知识库和工具台为什么合在一个 Spring Boot 里，而不是拆服务？**

追问：

- 检索：FULLTEXT 和 `content_text` 各解决什么？HTML 笔记怎么搜正文？
- 分享链接不登录可读，token 够不够随机？取消分享后旧链接呢？

- PDF 导出为什么走本机 Chrome 而不是 iText？服务端没有浏览器怎么办？

### 11. 知识库附件：分片上传与断点续传

**Q：笔记附件最大 2GB，你怎么传？断了怎么续？涉及哪几个接口？**

- 小程序为什么还走整包？
- 和 `GET content` 的 Range 是不是一回事？
- 两台实例 scratch 不共享会怎样？Limiter 是进程内的还是分布式的？

代码锚点：`KbFileUploadController`（6 个 uploads 接口）+ `KbFileUploadService`（scratch 落片、幂等 PUT、CAS complete）+ `KbUploadLimiter`；前端 `kb.api.ts#uploadFileChunked`、`FilePanel.vue`。整包仍在 `POST /api/v1/kb/files`，上限 100MB。

完整方案、接口表、口述骨架：[个人知识库_附件分片上传与断点续传.md](./个人知识库_附件分片上传与断点续传.md)。

**可能被追：** 多实例？——闸门和 scratch 都在单机，要扩得换共享盘或云 multipart。主动说边界比装成已水平扩展好。

**别说：** 「HTTP Range 上传」；「已经接了 S3 官方三步协议」；把 AIFactory 百万语料 QPS 套到这个知识库。

## 优先 8 道（口述 60～90 秒）

时间不够就练这组。每题：**骨架 → 可能被追的一句 → 别说**。

### 1. 为什么分表 + 分槽，不用 Kafka？

**骨架：**  
四个工具产物和中间态不一样：视频有下载/转写/理解，成片有分镜/配音/渲染。塞一张大表要么到处 `if type`，要么一堆空列。  
调度也拆开：每个 Scheduler 自己持有 `TaskSlotKernel`，视频最多 2 个并发，避免和成片抢同一组槽。槽在**进程内存**里，DB 只存任务状态。  
不用 Kafka，是因为现在就是单机小规格、任务量不大；上消息队列还要多一个组件和消费积压。HTTP 只接单，重活进自己的线程池。

**可能被追：** 重启怎么办？——启动把卡在 DOWNLOADING 等运行态的记录标 FAILED，避免内存槽是空的、库里却占着「正在跑」。

**别说：** 「全局一把槽」；「Kafka 不高级所以没用」；「已经能水平扩展」。

---

### 2. 视频提取状态机 + 进程重启

**骨架：**  
提交后 `PENDING`，调度抢到槽才跑：`DOWNLOADING → TRANSCRIBING → UNDERSTANDING（可选）→ SUMMARIZING → SUCCESS`。任一步失败进 `FAILED`，也可 `PAUSED`。  
暂停是协作式：步骤边界看标记，不是立刻杀 OS 进程。HTTP 线程不跑 yt-dlp。  
重启：孤儿运行态统一 FAILED，用户点重试再入队。进度靠 SSE，列表接口兜底。

**可能被追：** hybrid 和 audio-only？——差在要不要跑画面理解；Omni 失败可以按配置回退抽帧，不一定整单死。

**别说：** 「失败自动从断点完美续跑」——当前重试是清产物再从 PENDING 跑，不是任意步骤断点。

---

### 3. LangChain4j / OkHttp 如何回滚

**骨架：**  
业务只调 `LlmChatClient`。下面两个网关，配置 `ai.chat-engine` 选 langchain4j 或 okhttp。Chat、总结、润色走这一层。  
TTS、Remotion、FLUX 协议完全不同，单独 Port，不让聊天框架代管。框架升级把流式/超时搞坏时，改一项配置回到 OkHttp，流水线代码不用动。

**可能被追：** 契约是什么？——超时、取消、流式、错误如何冒泡；两套必须行为接近，否则「可回滚」是假的。

**别说：** 「LangChain4j 管了整个 AI 中台」。

---

### 4. 文章 SSRF 具体怎么防

**骨架：**  
用户给任意 URL，服务端去拉，就可能打到本机或云元数据。  
先校验 scheme（只允许 http/https）、禁止 userInfo、校验 host；DNS 解析后看 IP 是不是私网/回环/链路本地。  
真正发请求用钉扎：连到已经校验过的地址，redirect 每一跳重新走校验。还有超时和大小限制。  
反爬站点不硬刚，产品上提供粘贴正文。

**可能被追：** 只禁 127.0.0.1 够不够？——不够。还有 `10/8`、`169.254.169.254`、IPv6 回环、DNS rebinding（解析时公网、连接时内网），所以要解析后校验 + 钉扎。

**别说：** 「我过滤了 localhost 就安全了」。

---

### 5. Agent 写工具为什么必须确认，userId 怎么强制

**骨架：**  
Agent 只是对话里调站内工具，不重写流水线。工具是白名单，实现 `AgentTool`，注册表按名字取，模型不能发明接口。  
读工具直接跑；写工具（创建提取/成片/出图/笔记）先发确认草案，用户点了才调现有 Service。  
确认 token 在内存，带 userId / 会话 / 参数，TTL，一次性消费；别人拿这个 id 用不了，也不会误删别人的 token。  
真正落库仍走各模块 Service 的当前用户隔离，不是模型自己拼 SQL。

**可能被追：** 为什么不用框架自动 tool-calling？——自动连跑会跳过确认，批量创建和误操作成本高；我们要的是站内操作 Agent，不是黑盒自驱。

**别说：** 「模型保证不会乱调」；「token 存在 Redis 集群里」（现在是单机内存）。

---

### 6. JWT 为什么 claims 不含 role，改密如何作废旧 token

**骨架：**  
Token 里只有 userId、email、token_version。角色每次请求读库，改会员或禁用立刻生效，不用等 JWT 过期。  
改密时 `token_version + 1`，过滤器拿 claim 和库里的比，对不上就当未登录。  
登出是前端删 token，服务端不维护黑名单——这是有意的简化。找回密码验证码和注册验证码用途分开；邮箱不存在也返回成功，防枚举。

**可能被追：** 登出后旧 token 在过期前还能用吗？——能，直到过期或改密。要全端踢下线目前靠改密抬版本，不是 logout 接口。

**别说：** 「JWT 登出已经服务端失效」；「role 写在 token 里」。

---

### 7. 笔记发 Halo：绑定、附件、失败影响范围

**骨架：**  
工具台不托管博客源码。发文走 `HaloPublishPort`。超管用 yml 里的平台站；普通用户必须自己绑站点 + PAT，禁止回落到平台令牌。  
PAT 落库前 AES-GCM 加密。发的是副本：私有附件先传到 Halo 再换链接，知识库原文不动。失败只影响这次发布，笔记还在。  
资讯是另一条链路，Horizon 写入公共表，不进个人笔记。

**可能被追：** 图片失败呢？——发文过程中附件上传失败应导致这次发布失败，而不是改掉用户笔记。

**别说：** 「我们把 Halo 和知识库做成同一个库」；「所有用户都发到我的博客」。

---

### 8. 扩成两台实例，先坏什么

**骨架：**  
现在按单机设计。两台 Java 会先坏三处：  
1. **槽位**：`TaskSlotKernel` 在各自进程内存，两台会各跑满并发，DB 里可能出现超卖运行中任务。  
2. **SSE**：连接打在哪台，进度事件在另一台发不出去，除非上 Redis pub/sub 或粘滞会话。  
3. **确认草案 / 验证码配额**：也在内存，A 机发的确认卡 B 机消费不了。  
要扩实例，得先把调度、推送、确认改成共享存储。现在没做，是规模还用不上。

**可能被追：** 那对象存储和 MySQL 呢？——这两处本来就是进程外的，扩实例反而要靠它们；先坏的是「误放在 JVM 里的协调状态」。

**别说：** 「已经是无状态微服务，扩容没问题」。

## 红线（对这个项目）

- 不编 DAU、付费人数、微信已收款。
- 不把 OKX 交易助手当产品能力讲（代码主路径已不在简历里）。
- 数字用简历口径：约 500 个 Java 文件、80+ 单测；不要再背旧的 350+。
- 被问「最大流量 / QPS」：说没有线上压力数据，设计目标是单机稳态，不要用华为项目的百万级导出套到这个站。
- 设计模式问穷了就停：kb / horizon / auth 主体没有硬套 Port，这是优点。
