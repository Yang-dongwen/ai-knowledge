# 个人知识库 · 富文本 / 媒体 / 附件在线预览

**日期**：2026-07-30  
**状态**：Phase A 已落地（PC + 后端）；移动端同步为 Phase B  
 
**背景问题**：
1. 仅 Markdown 门槛高，无法在文档中插图/视频  
2. 需要 Word / Excel / PPT / PDF 等文件上传与在线预览  

---

## 1. 产品决策

| 能力 | 方案 |
|------|------|
| 默认编辑器 | **所见即所得富文本**（WangEditor），非技术用户主路径 |
| Markdown | **保留**：`contentFormat=markdown` 旧笔记兼容；可手动切换「源码/MD」 |
| 正文格式 | `content_format`：`html` \| `markdown`（默认新建为 `html`） |
| 图/视频入文 | 上传到对象存储 → 插入带鉴权 URL 的 `<img>` / `<video>` |
| 附件 | 独立 `kb_file` 表，可挂笔记；支持 PDF/Office/图片/视频等 |
| 预览 | 见 §4 |

---

## 2. 数据模型

### 2.1 `kb_note` 增量

```sql
ALTER TABLE kb_note
  ADD COLUMN content_format VARCHAR(16) NOT NULL DEFAULT 'markdown'
  COMMENT 'html|markdown' AFTER content;
```

### 2.2 `kb_file`

| 字段 | 说明 |
|------|------|
| id | 雪花 |
| user_id | 隔离 |
| note_id | 可空（编辑中先传后挂） |
| original_name | 原始文件名 |
| content_type | MIME |
| size_bytes | 大小 |
| object_key | 存储 key |
| kind | image / video / audio / pdf / office / other |
| created_at | |

存储 key：`{env}/kb/{userId}/{fileId}/{safeName}`

---

## 3. API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/kb/files` | `multipart file` + 可选 `noteId` |
| GET | `/api/v1/kb/files` | `?noteId=` 列表 |
| GET | `/api/v1/kb/files/{id}` | 元数据 |
| GET | `/api/v1/kb/files/{id}/content` | 流式内容（支持 `?access_token=`） |
| DELETE | `/api/v1/kb/files/{id}` | 删库+删对象 |
| POST | `/api/v1/kb/files/{id}/bind` | 绑定 noteId |
| 笔记 | create/update 增加 `contentFormat` | |

---

## 4. 在线预览策略

| 类型 | Phase A | 后续 |
|------|---------|------|
| 图片 | 页面 `<img>` | — |
| 视频 | `<video controls>` | — |
| PDF | iframe / embed（同源 content URL） | pdf.js 增强 |
| Word(.docx) | 前端 mammoth → HTML 预览 | OnlyOffice |
| Excel(.xlsx) | 前端 SheetJS → 表格 | OnlyOffice |
| PPT(.pptx) | **先下载**，提示暂无幻灯预览 | OnlyOffice / 转 PDF |
| 旧 .doc/.xls | 仅下载 | 服务端 LibreOffice 转 PDF |

Office 完整协同预览需要 OnlyOffice/Collabora 独立服务，**不进 Phase A**。

---

## 5. 分阶段

| 阶段 | 范围 |
|------|------|
| **A（本次）** | 后端文件 API；PC 富文本+插图视频；附件列表；图/视频/PDF/docx/xlsx 预览 |
| B | 移动端同步；分片大文件；PPT 转 PDF |
| C | OnlyOffice 在线编辑（可选） |

---

## 6. 限制（默认）

- 单文件：图片 10MB、视频 100MB、其它 30MB（可配置）  
- 正文 HTML 最大约 2MB  
- 禁止可执行脚本 MIME
